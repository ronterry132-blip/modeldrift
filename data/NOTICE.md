# Price catalog notice

`prices.json`, `aliases.json`, and `deprecations.json` are generated by `scripts/refresh-prices.mjs`. Edit `overrides.json` when a model has to be pinned, then re-run the script.

## Source we ship

Prices are transformed from [BerriAI/litellm](https://github.com/BerriAI/litellm) `model_prices_and_context_window.json` (repository root, outside `enterprise/`).

Verified 2026-10-21 from the upstream LICENSE:

- Files under `enterprise/` use the BerriAI Enterprise license.
- Everything else in that repository, including the model price JSON, is MIT, Copyright (c) 2023 Berri AI.

ModelDrift converts `input_cost_per_token` and `output_cost_per_token` (USD per token) into USD per 1M tokens, copies `deprecation_date` when it is a real `YYYY-MM-DD`, and adds provider-prefix aliases such as `openai/gpt-4o`. The MIT license notice above has to travel with substantial copies of that data. This repository's own code is also MIT; see the root `LICENSE`.

`overrides.json` is ModelDrift curation (retired snapshots LiteLLM has dropped, plus alias fixes). Those rows are not copied from LiteLLM.

## Source we do not ship

[sdeep27/llm-pricing-api](https://github.com/sdeep27/llm-pricing-api) was checked on 2026-10-21. GitHub reports `license: null`, and the repository has no LICENSE file. ModelDrift does not fetch, copy, or redistribute that dataset. The daily refresh workflow does not call it.
